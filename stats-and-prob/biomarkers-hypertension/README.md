# Biomarkers & Hypertension (advanced reference)

The original Phase-1 study: which blood biomarkers associate with hypertension in
CDC NHANES 2017–2018 (5,437 adults). [phase-01-report.html](phase-01-report.html)

Kept as advanced reference material — the lesson track starts with the simpler
bricks. `scripts/01_build_dataset.py` downloads the raw NHANES files from the CDC
itself, so the study reproduces from scratch (raw files are git-ignored).
