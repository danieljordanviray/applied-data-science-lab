The tutorial — statistics from zero

1. The question every experiment asks

A farmer gives 40 plants the old fertilizer and 40 plants a new one. The new-fertilizer plants grew 2 cm taller on average. Did the fertilizer really work — or did those 40 plants just get lucky? That question, real effect or just luck?, is what this whole page is about. Luck has a formal name: [sampling variability] — the fact that every new sample comes out a little different.

Try this: Press it a few times. Watch the verdict flip even though the truth never changed.

2. The truth — which real life hides from you

In real life you never get to see the true effect. Here, you set it with the True effect slider. The blue curve is ordinary plants; the orange curve is fertilized plants. Slide the effect to 0 and the curves sit exactly on top of each other — the fertilizer does nothing. Scientists call the true difference the [effect size].

3. Why one experiment can lie

Plants differ from each other — some are just vigorous. That plant-to-plant spread is the Noise slider [standard deviation]. Because of it, every experiment draws a slightly different sample, and the measured difference wobbles around the truth. Small samples wobble violently; big samples barely wobble. That wobble is why single experiments mislead.

4. The p-value, in plain words

The [p-value] answers exactly one question: if the fertilizer did nothing, how surprising would my result be? p = 0.03 means: if the fertilizer really did nothing, you'd still see a result at least this surprising — in either direction — about 3% of the time, just by luck. Small p → very surprising → we declare the result significant [statistical significance]. The usual cutoff is 0.05.

⚠️ The classic trap: p is not "the chance the fertilizer works." It's "the chance of a result this surprising if nothing were going on."

5. The 5% tax on crying wolf

Set the true effect to 0 — the fertilizer does nothing — and run 1,000 experiments. About 5% still flash "significant!" That's the built-in price of the 0.05 rule: even when nothing is real, 5% of experiments cry wolf [Type I error / false positive]. Don't take this page's word for it — the prove-it box in the lab lets you check.

6. Power — catching what's real

[Statistical power] asks the opposite question: when the effect is real, what percentage of experiments actually detect it? Slide Plants per group up and watch power climb. The painful lesson: small sample + small effect = you'll miss a real effect most of the time. That's why underpowered studies fail — not because the idea was wrong, but because the net had holes.

🔎 Prove-it box — don't trust this page on faith.
Two self-checks you can run right now: (1) set True effect = 0 and run 1,000 experiments — the "significant" rate should sit near 5%, exactly what the 0.05 rule predicts; (2) set True effect = 4, Noise = 8, Plants = 64 — power should land near 80%, the textbook rule of thumb. If either number were way off, this page would be broken.

Built as a learning toy. Under the hood: Welch's two-sample t-test [the standard test for comparing two group averages], p-values computed from the t-distribution [the curve t-statistics follow when nothing is going on], and all randomness simulated live in your browser — no servers, no tracking.
