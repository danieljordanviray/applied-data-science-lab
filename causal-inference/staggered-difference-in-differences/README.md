# Staggered Difference-in-Differences

[Read the post](staggered-difference-in-differences.html)

A program rolls out to different regions at different times, so the textbook
difference-in-differences comparison breaks. A four-region toy example
(Raleigh, Boston, Denver, Phoenix - CRISPR gene-therapy centers opening in
waves) shows the staggered fix: measure each wave against a holdout or
not-yet-treated regions using a Before / Wait / After rule, calculate each
wave's DiD, then pool them into one number for the program's effect
[Callaway & Sant'Anna group-time ATT]. Includes an anticipation-effects
example, assumptions, and limitations. All data is a made-up teaching
example.
