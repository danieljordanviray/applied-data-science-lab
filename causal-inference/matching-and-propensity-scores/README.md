# Matching and Propensity Score Matching: The Practical Playbook

[Read the playbook](matching-and-propensity-scores.html)

When you can't run a randomized trial, rebuild a fair comparison from
observational data. One diabetes example (metformin vs. an SGLT2 inhibitor)
carries the whole playbook: covariate imbalance and balance, fine balance and
the ATT, Mahalanobis distance, greedy vs. optimal matching, calipers and
positivity, Table 1 and the Love plot, SMDs, permutation tests and McNemar's
test, paired t-tests, Rosenbaum sensitivity analysis (Γ), and propensity
scores — the balancing property, overlap, trimming the tails, the logit
transformation, and the 0.2 × SD caliper rule. Interactive charts and
simulations run in the page itself.

All data is a made-up teaching example — no real patients, no real claims.
Adapted from Jason Roy's "A Crash Course in Causality" (Penn Medicine).
