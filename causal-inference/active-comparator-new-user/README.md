# Active-Comparator, New-User Cohort Study with Difference-in-Differences

[Read the study](active-comparator-new-user.html)

Does Ozempic lower the cost of obesity care? A claims-only study design,
explained end to end with a six-member toy example that can be checked by hand:
how claim lines become a member-month cost table, how group averages are
built, what the graph is plotting, what the counterfactual line means, and how
the four group averages produce the difference-in-differences estimate
(-$120/month in the toy example).

All data is a made-up teaching example — no real members, no real claims.
